# tophat-slide-downloader
The website my professor uses to present slideshows, `app.tophat.com`, doesn't support direct image download, so saving the images from the slideshow was a huge hassle. Instead of manually saving each HTTP response as an image, I wrote this python script to somewhat automate that process. 

First, you have to have your browser developer tools open to the network tab, preferably with the `Disable Cache` option checked. Next, right click on any request and select `Save all as HAR` to save the entire network stream to a HAR archive that this script can parse. Finally, launch a terminal, change to the `binary/dist/` directory and launch the `main` binary (compiled with pyinstaller). This will ensure you won't need to create your own virtual environment with the required python libraries installed. However, you're free to do so if you don't trust anything not compiled from source, they should function the same.
